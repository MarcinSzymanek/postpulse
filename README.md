A modified version of React refresher part of Udemy course: Next.Js 15 & React: The Complete Guide by Maximilian Schwarzmuller. If you're interested in the Udemy course, do check out [the course here](https://www.udemy.com/course/nextjs-react-the-complete-guide/?couponCode=KEEPLEARNING), I found it to be a great refresher on using modern React, and can definitely recommend it.

I use it as a training ground for backend and CI testing, and plan to add functionality such as auth and protected routes.

Currently contains two projects:

- react-poster

  - Frontend site in React to a post a comment site from
  - Modified to include a signup page

- dummy-backend
  - Node.js express backend using local JSON for storage
  - Modified to include signup functionality
  - Uses Github Actions + Jest to automate unit tests

Currently I plan to add Postman endpoint tests to the CI, and expand the functionality to include proper login.
